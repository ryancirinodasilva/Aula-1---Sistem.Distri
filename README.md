# Aula-1---Sistem.Distri

O que foi proposto em aula
A aula introdutória teve como foco apresentar os conceitos básicos de Sistemas Distribuídos, partindo de exemplos do dia a dia (WhatsApp, Instagram, Netflix, Spotify, Uber, iFood, Internet Banking, Google Drive, etc.) para mostrar que já interagimos com sistemas distribuídos o tempo todo, muitas vezes sem perceber.

Foram discutidas as diferenças entre Sistemas Centralizados e Sistemas Distribuídos, destacando que um sistema distribuído é formado por computadores ou processos independentes que:
Estão conectados por uma rede;
Comunicam-se por troca de mensagens;
Compartilham recursos ou serviços;
Coordenam suas ações;
Trabalham para atingir um objetivo comum.

Também foi discutido por que criar sistemas distribuídos, considerando:

Escalabilidade
Desempenho
Disponibilidade
Tolerância a falhas
Compartilhamento de recursos
Distribuição geográfica
